주소: https://edunity21.github.io/ojakgyo/

## 폴더 구성

- `index.html` — 플랫폼 (홈 · 연구 설계 · 오 · 作 · 橋 · 다음 다리 · 실천 결과 · 일반화 · 현장 기록 · 자료실)
- `report.html` — 연구보고서 · 요약서 전문
- `img/` — 사진 59장

## 올리는 방법 (GitHub 웹)

1. github.com에서 `ojakgyo` 이름으로 Public 레포지터리를 만듭니다.
2. 레포 첫 화면의 "uploading an existing file"(또는 Add file → Upload files)에 `index.html`, `report.html`, `README.md`, `img` 폴더를 한꺼번에 끌어다 놓습니다. (모두 62개라 한 번에 올라갑니다)
3. 진행 막대가 모두 사라지면 Commit changes를 누릅니다.
4. Settings → Pages에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
5. 1~2분 뒤 https://edunity21.github.io/ojakgyo/ 에서 확인합니다.

## 고칠 때

사진은 그대로 두고 `index.html`, `report.html`만 같은 자리에 다시 올리면 덮어써집니다.
